# 🐼 Pandas Practice & Exercises Repository

A comprehensive collection of Jupyter Notebooks dedicated to mastering **Pandas** for data manipulation, cleaning, and analysis. This repository serves as a personal workbook containing various exercises, real-world datasets, and practical challenges designed to build strong data science foundations.

---

## 🚀 Repository Purpose

The goal of this repository is to document my learning journey and hands-on practice with the Pandas library. It transitions from core foundational concepts to advanced data transformation techniques, applied across multiple standalone exercises and projects.

---

## 📚 Core Concepts Covered

Every notebook in this repository focuses on solving specific data problems using different Pandas functionalities:

* **Data Ingestion & Exploration:** Loading datasets (CSV, Excel, JSON) and performing initial inspections (`head()`, `info()`, `describe()`).
* **Data Cleaning:** Handling missing values (`dropna()`, `fillna()`), removing duplicates, and correcting data types.
* **Filtering & Selecting:** Advanced indexing, boolean masking, and querying specific data slices.
* **Aggregation & Grouping:** Using `groupby()`, pivot tables, and custom aggregation methods to summarize data.
* **Merging & Joining:** Combining multiple datasets efficiently using `merge()`, `join()`, and `concat()`.
* **Time Series Analysis:** Working with DateTime objects, resampling, and shifting time-based data.
